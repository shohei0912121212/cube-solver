# キューブソルバー(ルービックキューブ解法アプリ)

公開URL: https://shohei0912121212.github.io/cube-solver/

`index.html` をブラウザで開くだけで動く 3×3 ルービックキューブ解法アプリ。依存ライブラリなし(フォントのみ Google Fonts)。

## 使い方
1. 色を選び、展開図または3Dキューブのマスをタップして手元のキューブの色を入力(中心固定:上=白、手前=緑)
2. 「解く」→ 約20手前後の解法を表示
3. 「次へ ▶」で1手ずつ3Dアニメーション再生(戻す/自動再生/任意の手へジャンプ可)

写真入力:「カメラで読み取る」(通常のWebサイトとして開いた場合。getUserMedia)で枠に合わせて1面ずつ読み取り。claude.ai の共有ページではカメラ禁止のため「写真を選ぶ」でアルバムから選択→ 枠を合わせて読み取り → 反映。各面の中心色を基準色にして Lab 色空間で判定し、各色9枚になるよう割り当てるので照明の色かぶりに強い。誤認識は展開図で修正。撮影順:緑→赤→青→オレンジ(白を上のまま左へ90°ずつ回す)→白(緑正面から手前に倒す・青が上)→黄(奥に倒す・緑が上)。画面のステップ表示と「上の色」の帯、「次」ガイド(次に押すボタンを枠で強調)で案内。

その他:スクランブル、完成状態に戻す、手動回転ボタン、手順入力(例 `R U R' U'`)、入力ミス検出(色の枚数・存在しない角/辺・ねじれ・反転・パリティ)。状態は localStorage に保存。

## 構成(index.html 1ファイル)
| 部分 | 内容 |
|---|---|
| `<script id="core">` | キューブモデル+ソルバー。Node でも `require` 可能(`module.exports`) |
| UI `<script>` | CSS 3D 描画、展開図エディタ、解法プレイヤー |

- ソルバー:Kociemba 二段階法。初期化(移動表・枝刈り表)約0.7秒、探索は最大1.5秒で最短に近い解を返す。Blob Worker で実行し UI を止めない
- 面番号 `0..5 = U R F D L B`、ステッカー番号は `U1..U9, R1..R9, F, D, L, B`(0..53)
- 手番号 `m = 面*3 + (0:90°, 1:180°, 2:-90°)`
- 3D:27個の cubie div、回転は該当層に CSS transition → 終了後に状態更新して再描画

写真読み取りの自動補正:
- 面の写真が90°/180°ずれていても、4096通りの向きから実在する配置を探して自動補正
- 赤/オレンジなど見分けにくいマスの読み違い(2マスの入れ替わり)を自動補正
- 同じ面を2回撮ったら(中心色がほぼ同じなら)警告

検証(Playwright・実物撮影は未実施):
- 撮影順と持ち方の案内が展開図の向きと一致することを3Dモデルで確認(6ステップ全て)
- アプリの3D描画で実物風の写真を作成(遠近・斜め最大12°・電球色/蛍光灯/暗所・テカリ・ぼけ)→ 6面読み取り → 解法を実行 → 完成、を7パターン全て成功(うち2パターンは面を90°傾けて撮影)

## テスト(Node)
`<script id="core">` の中身を `core.js` に書き出し、ランダムスクランブル→`solve`→適用→`isSolved` を確認(30問全て成功、平均約19手)。
