キューブソルバー

色を入力して「解く」を押すと、揃えるまでの手順を3Dで1手ずつ再生します。

—
ドラッグで視点を回転

解法

0 / 0
–「解く」を押すと、ここに次の1手の説明が出ます。

手順は白を上・緑を手前にした向きが基準です。持ち替えずに順番どおり回してください。

写真で読み取る

「カメラで読み取る」で枠に9マスを合わせて1面ずつ読み取ります。カメラが使えない画面では、先に撮った写真を「写真を選ぶ」で1枚ずつ選び、枠を合わせて読み取ってください。

色を入力

色を選んでから、展開図か3Dキューブのマスをタップします。中心の色は固定です(上=白、手前=緑)。

手動で回す

R / L
右面 / 左面を時計回りに90°
F / B
手前の面 / 奥の面を時計回りに90°
′(R′)
反時計回りに90°
