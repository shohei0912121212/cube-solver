# パイプ本数カウンター

パレット側面の写真から、丸パイプ・角パイプの本数を数える棚卸用ツールです。
スマホのブラウザで開くだけで動きます。インストールは要りません。

**→ https://shohei0912121212.github.io/cube-solver/pipe-counter/**

## 使い方

1. **写真** — パレットの木口の面を正面から、1山まるごと撮る
2. **自動検出** — 木口を自動で拾って印を付ける
3. **確認・修正** — ピンチで拡大し、抜けはタップで追加、余分な印はタップで削除
4. **記録** — 場所とサイズを入れて保存。最後にCSVで書き出す

「番号付き画像」を保存すると、木口に通し番号を振った写真が残ります。
**あとから検算できる棚卸の証跡**として使えます。

## 自動検出がうまくいかないとき

歯車アイコンから調整できます。

| 症状 | 対処 |
|---|---|
| 検出が少なすぎる | 検出感度を上げる |
| 影やゴミを拾いすぎる | 検出感度を下げる、または「小さい検出を除外」を上げる |
| 印が写真に埋もれて見えない | マーカーの色を変える（メッキ材はマゼンタ、錆材はシアンが見やすい） |

## 撮影のコツ

- 木口の面に対して**できるだけ正面**から（斜めだと奥の段が潰れます）
- 1山を**1枚に収める**
- 逆光を避け、穴の影がはっきり出る明るさで
- サイズ混在の山は**サイズごとに分けて**撮る

## 精度について

自動検出は完璧ではありません。錆、テカリ、木口の潰れ、斜め写りがあると落ちます。
**必ず番号付き画像で目視確認してから在庫表に反映してください。**
このツールは数える手間を減らすためのもので、人の確認を置き換えるものではありません。

## 技術メモ

- 依存ライブラリなし。`index.html` 1枚で完結
- 写真は**端末の外に出ません**。読み込みも解析もブラウザ内で完結します
- 記録はブラウザの localStorage に保存されます。端末を変えると引き継がれないので、
  棚卸が終わったらCSVを書き出してください
- 検出方式: 積分画像による局所適応二値化 → 連結成分ラベリング → 面積の中央値で足切り
  → 近接検出のマージ → 上から下・左から右の順に採番
- 一度開けば、オフラインでも動きます
